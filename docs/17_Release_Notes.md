# 17 Release Notes: v1.0.0 "Steel Foundation"

## 1.0.0 (August 2026)
This is the initial production-ready release of the Deshmukh Hardware & Steel ERP.

### 🚀 New Features
- **Cloud-Only Architecture**: Fully decoupled from local persistence, optimized for real-time Spring Boot integration.
- **Enterprise Design System**: Material 3 "Industrial Blue" theme with full token standardization.
- **Global Search**: Instant cross-module search for SKUs, Invoices, and Contacts.
- **Financial command center**: Live cash book and transactional ledger.
- **Professional Reporting**: PDF tax invoice generation and Excel stock export.

### 🛡️ Security
- **RBAC**: Role-Based Access Control implemented for Admin, Manager, and Employee roles.
- **JWT**: Secure token persistence using `flutter_secure_storage`.

### 🛠️ Technical Improvements
- **Riverpod 2.6**: Full migration to generated providers for type safety.
- **Drift Removal**: Stripped out legacy local database logic to reduce app size and complexity.
- **Clean Architecture**: Refactored the entire codebase into feature-first layers.
